# DB_EEG_Classifier

Noninvasive electroencephalogram (EEG) technology is used in the medical field to detect neural abnormalities and diagnose brain disorders including epilepsy, stroke, and tumors. The use of EEG hardware is also attributed to diagnosis of Alzheimer’s Disease (AD) in machine learning applications. Within the medical field, psychiatric surveys and brain scanning technology such as computed tomography (CT), positron emission tomography (PET), and magnetic resonance imaging (MRI) are utilized by doctors to diagnosis a patient as having AD. In recent years, EEG has become known to be advantageous in cost and accessibility to patients even outside the hospital. These advantages cause reason for machine learning applications trained on EEG data to be an effective use-case in detecting AD. This project aims to optimize the advantages in using EEG by providing an interactive user interface through which viewers may easily visualize the steps in preparing EEG data for a machine learning model and the accuracy rate of a machine learning model when taking in untrained data.
